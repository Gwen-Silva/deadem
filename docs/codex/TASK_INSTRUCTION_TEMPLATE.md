# Template de Instrução Codex — Contrato v1

Use `coordinationPolicyVersion: 1` e mantenha estes blocos exatamente nesta
ordem. Cada bloco deve ser não vazio.

## 1. Reasoning complexity

Complexidade necessária e motivo.

## 2. Objective

Resultado técnico único e verificável.

## 3. Technical context

Contexto existente necessário para executar.

## 4. Confirmed state

Fatos aceitos por Work, status atual e autoridade de aceitação.

## 5. Expected base commit

SHA de 40 caracteres igual ao último commit aceito.

## 6. Branch/environment

Branch, repositório e restrições do ambiente.

## 7. Allowed scope

Caminhos e ações autorizados.

## 8. Protected areas

Caminhos, dados e ações proibidos.

## 9. Expected changes

Mudanças técnicas esperadas.

## 10. Acceptance criteria

Critérios verificáveis; aprovação final continua com Work.

## 11. Mandatory tests

Comandos e resultados exigidos.

## 12. Required evidence

Artifacts e registros necessários para validação independente.

## 13. Commit policy

Quantidade, mensagem, staging e push autorizados.

## 14. Stop conditions

Condições que interrompem a execução sem autoautorizar alternativas.

## 15. Return-report format

Seções obrigatórias do relatório Codex conforme
`docs/codex/CODEX_REPORT_TEMPLATE.md`.
